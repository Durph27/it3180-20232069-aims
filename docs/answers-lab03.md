# Lab 03 – Câu hỏi

1. **Merge base là gì?** Là commit chung gần nhất của hai nhánh trước khi chúng tách ra. Git dùng nó để xác định phần thay đổi cần hợp nhất.
2. **Vì sao `master` và `release/*` phải dùng `revert`?** Đây là lịch sử đã chia sẻ; `revert` tạo commit mới để đảo thay đổi mà không viết lại lịch sử của mọi người.
